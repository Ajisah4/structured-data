# Object Methods

<EpicVideo url="https://www.epicweb.dev/tutorials/structured-data/6-object-methods/break-object-methods" />

👨‍💼 Great work! You used object methods to convert between objects and arrays.

You learned:

- 🗂️ **`Object.keys`** and **`Object.values`** for listing data
- 🧾 **`Object.entries`** for key/value pairs
- 🧱 **`Object.fromEntries`** to rebuild transformed objects

These tools make it easy to apply array methods to object data.
